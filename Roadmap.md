# Family Wealth Operating System (FWOS)

**Document:** `ROADMAP.md`
**Current FWOS Version:** 3.0.0
**Status:** Active
**Started:** July 2026

---

# 1. Objective

This roadmap defines the phased development of the Family Wealth Operating System.

The sequence follows one core rule:

> Financial logic must be validated before software is built around it.

The project will therefore progress through:

1. Foundation
2. Data Collection
3. Goal Modelling
4. Portfolio Strategy
5. Implementation
6. Risk and Protection
7. Structured Data
8. Documentation
9. Analytics
10. Automation and AI

# 17. Phase 15 — AI-Assisted FWOS

**Target Version:** 5.x

## Objective

Build an AI-assisted decision-support layer.

Potential capabilities:

* Read structured family data
* Evaluate investments against FWOS rules
* Detect allocation drift
* Identify goal-funding gaps
* Generate review questions
* Compare investment products
* Explain portfolio changes

## AI Guardrail

AI remains a decision-support system.

It does not silently modify:

* Investment policy
* Financial data
* Portfolio holdings
* Goal assumptions

Material changes require explicit approval.
